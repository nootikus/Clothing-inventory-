Clothing Inventory Shared App
=============================
Cross-platform PWA for Android + iPhone.

This package needs a Supabase project for shared syncing. See SETUP.md.

The app supports 50 boxes, 40 spaces per box, search, add/edit/delete,
listing links, price/sale/profit calculations, and realtime syncing.

For a secure production version, add Supabase Auth + RLS before sharing
the database widely.
